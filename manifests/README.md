# Source provenance

Actual frozen source identifiers, local video SHA-256 hashes, annotation/label hashes,
and exclusions are written to each run's `source_provenance.json`. Full annotations,
labels, frame timelines, local paths, and exposure manifests remain in ignored local files.

Upstream access: https://github.com/MME-Benchmarks/Video-MME#-dataset

The project's official dataset link currently redirects from `lmms-lab/Video-MME`
to `lmms-eval/Video-MME`. Annotation revision is resolved to an immutable commit.
The adapter uses `videomme/test-00000-of-00001.parquet` and complete original videos.
Only academic research is permitted by the upstream terms. Obtain the data through
the official distribution; do not redistribute its questions, labels, or videos here.

All pilot sources are development exposure, never untouched confirmation data.
